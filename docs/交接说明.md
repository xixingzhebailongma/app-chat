## 3. 你要做的（核心）

实现真实 go-backend（监听 8081，替代 `scripts/mock-go-backend.py` 这个替身）：

**出向**（网关主动调你，字段名见 `wechat-gateway/config/upstream.json`）：

| 端点 | 用途 |
|---|---|
| `POST /auth/login` | 账号密码登录 → `{user:{user_id,username,name,role}}` |
| `GET /users/{user_id}` | 短信兜底查手机号（带 `X-Internal-Token`） |
| `GET /devices?space_id=` | 设备列表 |
| `POST /devices/{type}/{id}/cmd` | 设备控制（`command` 仅 on/off/toggle） |
| `GET /ws` | WebSocket 代理 |

**入向**（你主动调网关，`X-Internal-Token` 鉴权）：`/internal/notify/send`（告警）、`/internal/oa/arrival-notify`（到校）、`/internal/user-roles/sync`、`/internal/spaces/sync`、`/internal/access-records`、`/internal/student-parents/sync`。

**关键约束（务必遵守）**：

- `role` 仅 `admin`/`teacher`；所有设备/告警/事件必须带 `space_id`（与 `user_spaces.space_id` 同源同值）。
- 告警字段 `transition` 精确取 `online->offline`（写错会静默 `skipped`，HTTP 仍 200，边侧不查响应体就丢告警）。
- 三表同步（roles/spaces/花名册）必须全量、删也要同步。
- **不要在 go-backend 里重复建 `user_spaces` 或重复鉴权**——权限过滤由网关做，你只提供原始数据。
